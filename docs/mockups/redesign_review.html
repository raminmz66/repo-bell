Senior UI/UX Review & Redesign Proposal

RepoBell Comprehensive UI/UX Overhaul

Combining user feedback with senior UI/UX audit standards from Impeccable (WCAG AA contrast, scannability, horizontal containment, progressive disclosure, and Ubuntu GNOME desktop integration).

Synthesized Design Decisions (User Feedback + Impeccable Audit)

1. Tray Signal-to-Noise

Tray popover filtered exclusively to repos with incoming team commits (behind > 0). Removed repetitive "Has unsaved changes" flooding.

2. "News" Definition

Local unsaved edits never elevate a repo into the news feed. Repos with 0 behind commits sit in "Up to date", eliminating dead-end cards.

3. Native Top-Right Flyout

Window positioned directly under top-bar indicators (x: screen_width - 420 - 16, y: 36). Fixed 420x640 size, no double OS titlebars.

4. Changed Files & Editor Links

Strict horizontal containment (overflow-x: hidden). Max height 180px with vertical scroll. File paths are clickable links that open in your editor.

5. Master Watch vs. Alerts

Primary switch in settings controls Watch vs. Stop Watching. Dedicated Bell toggle (🔔 / 🔕) controls alerts. Hidden ... menu removed.

6. Collapsible Drawer Cards

Cards act as collapsible accordions. Start expanded by default; can be collapsed to sleek 50px rows with the Update button directly accessible.
